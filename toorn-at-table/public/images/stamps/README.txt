# Drop your country stamp PNGs in this folder, named after the location
# slug used in src/content/travel.ts. Examples:
#
#   public/images/stamps/nederland.png
#   public/images/stamps/spanje.png
#   public/images/stamps/japan.png
#   public/images/stamps/verenigde-staten.png
#
# Slug list (all 27):
#   nederland, belgie, luxemburg, duitsland, frankrijk, zwitserland,
#   oostenrijk, tsjechie, hongarije, roemenie, uk, ierland,
#   denemarken, zweden, noorwegen, finland, spanje, portugal,
#   italie, vaticaan, griekenland, turkije, marokko, senegal,
#   gambia, verenigde-staten, japan
#
# Recommended: transparent PNG, 1024×1024, illustration fitted inside
# a circular boundary. The grid renders square cells with object-contain
# so anything that fits the square will show without distortion.
#
# When a file is missing the StampGrid renders an SVG fallback stamp
# (rings + curved country name + Alfa Slab country code + ANNO year),
# so you can roll out illustrations one country at a time.
